# xhs-guideword-en

将辽宁景区**英文**导游词转化为小红书图文发布包的 Skill，专用于 2026 辽宁导游资格证英语口试（机考）备考内容——5 分钟口试讲解版（通常 300–400 词）。

## 功能

- 输入英文导游词（docx 或纯文本），生成**白底庄重简约跟读卡 7 张**（3:4，1080×1440px）：
  - 白底封面 + 讲解卡 1–6（Cambria 衬线英文，零角标、零装饰）
- 输出完整稿 docx 附件（手写最小合法 docx，不依赖 python-docx）+ 发布包 markdown
- 纯矢量文字卡（零实景图、零 AI 图），无需 AI 标识

## 与中文版区分

- 本 skill 仅处理**英文**讲解稿；中文口试稿走 `xhs-guideword-cn`（深蓝品牌卡）。
- 英文版视觉走「白底庄重简约」路线，与中文版深蓝品牌卡形成双语矩阵区分。

## 合规要点（发布前必查）

- **时长铁律**：一切时长标注以口试 **5 分钟**为准；模板/外部素材误标"3 分钟/2 分半"属 bug 必改。
- **史实**：WebSearch 核实年份/数据/称号/英文译法；辽宁文旅口号官方译法 `Sentient mountains and seas, vast and tranquil Liaoning`。
- **鸭绿江红线**：断桥专版 vs 沿线游全景（5 站）严格区分；群雕 26 人物 = 260,000 志愿军首批过江（禁 2,600,000）；友谊桥 1937 动工 1943 通车（禁 built in 1937）。
- **极限词**：史实类"第一"等历史陈述豁免；禁"最/唯一"营销绝对化。
- **站外引流**：正文零"公众号/私信/加微信/外链"；引流只走评论区置顶。
- **标题 ≤20 字**、**描述栏 ≤950 字符**、机考录制限时 5 分钟。
